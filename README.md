# Homebrew Tap for Safe Drive Ejector

Official Homebrew tap for [Safe Drive Ejector](https://github.com/siraj-bd/Safe-Drive-Ejector-macOS) on macOS.

## Quick Install

To install the macOS Universal app:

```bash
brew install --cask siraj-bd/tap/safe-drive-ejector
```

Or tap the repository first:

```bash
brew tap siraj-bd/tap
brew install --cask safe-drive-ejector
```

## Update

```bash
brew upgrade --cask safe-drive-ejector
```

## Uninstall

```bash
brew uninstall --cask safe-drive-ejector
```
